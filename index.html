H5P-Export

Wandelt eine .h5p-Datei in ein HTML5-Paket um, das per Doppelklick im Browser läuft – ohne Server, ohne Internet.

Dieser Browser ist zu alt. Bitte eine aktuelle Version von Chrome, Edge, Firefox oder Safari verwenden.

Datenschutz: Ihre Datei wird ausschließlich in Ihrem Browser verarbeitet und nicht hochgeladen. Nur wenn das Nachladen vom H5P-Hub eingeschaltet ist und Bibliotheken fehlen, wird der Name des Inhaltstyps (z. B. „H5P.Blanks“) bei api.h5p.org abgefragt.

H5P → HTML5-Paket

Was ist im Ergebnis?

Eine ZIP-Datei. Entpacken, dann index.html doppelklicken. Enthalten:

  • index.html – Startseite
  • h5p/ – Inhalt und Bibliotheken
  • player/ – der H5P-Player (h5p-standalone 3.8.2)
  • start.bat / start.command – Start über einen lokalen Webserver, falls der Browser Dateien blockiert

Fehlen der Datei Bibliotheken („Content-only“-Export), werden sie aus 64 mitgelieferten Bibliotheken ergänzt. Formeln (LaTeX wie \( … \)) werden wie auf einer H5P-Plattform automatisch mit H5P.MathDisplay dargestellt – auch offline. H5P arbeitet versionsgenau: Es wird immer genau die Version verwendet, mit der der Inhalt erstellt wurde.

Lumi-Korrektur: Core-API senken

Für die Lumi-Meldung api-version-unsupported (current: 1.27, required: 1.28). Erzeugt eine Kopie der .h5p-Datei, in der die geforderte Core-API-Version gesenkt ist. Der Inhalt bleibt unverändert.
